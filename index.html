Cara Kerja Up-to-Date

GitHub Pages untuk frontend, API terpisah untuk data fresh

GitHub Pages hanya bisa host file statis (HTML/CSS/JS). Scraper butuh Node.js. Jadi arsitektur yang benar:

01
Frontend di GitHub PagesRepo ini (Anggito09/beligo) → Settings → Pages → Deploy from main branch. Domain: anggito09.github.io/beligo
02
Backend di Vercel / Cloudflare Workers (gratis)Folder /api di repo ini sudah siap. Deploy ke Vercel → jadi beligo.vercel.app/api/search?q=laptop. Frontend fetch ke sana.
03
Up-to-date: Cron 15 menit + On-DemandKeyword populer di-cron tiap 15m. Keyword sepi di-scrape saat user search. Cache di Redis/Upstash. Market baru tinggal tambah 1 file di api/scrapers/.
04
Tambah Marketplace BaruCopy api/scrapers/_template.js → isi selector → daftarkan di api/scrapers/index.js. Otomatis ikut ranking.
MVP sekarang pakai mock data biar bisa langsung live di GitHub Pages tanpa backend. Ganti 1 baris di app.js: const USE_MOCK = false setelah backend jadi.
